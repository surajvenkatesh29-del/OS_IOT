# GitHub Upload Guide

## 1. Create repository

Create a new GitHub repository named:

`smart-traffic-signal`

Do not add another README if you are uploading this repository as-is.

## 2. Initialize locally

```bash
git init
git add .
git commit -m "Initial smart traffic signal project"
git branch -M main
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```

## 3. Recommended repository description

`Raspberry Pi and Ubuntu Linux traffic signal demonstrating OS priority scheduling with IR sensors, LEDs, POSIX threads, mutex synchronization, and libgpiod.`
